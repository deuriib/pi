# E-010: bin global + package instalado (nivel global)

**Fecha:** 2026-09-29
**Síntoma:** `deu` global resolvía al bundle pelado de coding-agent linkeado
(0.87.1) sin launcher, sin `PI_CODING_AGENT_DIR=.deu` y sin package deu.

## Cambios en el entorno (reversibles, fuera del repo)

- `npm link --force` de `packages/deu` en el prefix de mise: `deu` →
  `node_modules/deu/dist/index.js` (launcher; antes bundle de coding-agent).
  Reversión: `npm unlink -g deu` + re-link de coding-agent si se desea.
- `deu install D:/2-Areas/GitHub/pi/packages/deu` (global): `deu list`
  muestra el user package. Reversión: `deu remove <path>`.

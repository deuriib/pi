## Hallazgo que motivó `dist/` (bloqueante global, resuelto)

`bin → ./index.ts` falla instalado: Node prohíbe type-stripping bajo `node_modules`
(`ERR_UNSUPPORTED_NODE_MODULES_TYPE_STRIPPING`). Decisión: launcher compilado con
esbuild a `dist/index.js` (shebang preservado, 1.6kB, solo builtins+lib); `bin`
apunta ahí; `files[]` incluye `dist/` (gitignored en dev); `prepublishOnly` lo
regenera. Las extensiones siguen en `.ts`: el runtime las carga por su propio
loader (igual que `pi-mcp-adapter/index.ts`).
